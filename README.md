# Portfólio — Renan Rodrigues Monteiro

Este é meu site pessoal, criado para apresentar um pouco sobre mim, minha formação e meus conhecimentos.

O site reúne informações sobre minha trajetória acadêmica, habilidades, formação complementar e formas de contato.

## Tecnologias utilizadas

- HTML5
- CSS3

## Como visualizar

Baixe a pasta do `portfolio`.
Abra o arquivo `index.html` em um navegador ou pela extensão live server no VS Code.
ou então abra pelo Github pages.
